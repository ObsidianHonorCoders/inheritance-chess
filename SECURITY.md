# Security Policy

## Supported Versions

Security fixes are provided for the latest `main` branch.

## Reporting a Vulnerability

Please do **not** open public issues for suspected vulnerabilities.

Report security concerns privately with the following details:
- Affected repository and commit/branch
- Reproduction steps
- Impact assessment (confidentiality/integrity/availability)
- Proposed mitigation (if available)

Until a private security mailbox is configured, report through repository maintainers listed in `CODEOWNERS` and request private handling.

## Response Targets

- Initial triage acknowledgement: within 3 business days
- Severity classification and remediation plan: within 7 business days
- Critical vulnerabilities: hotfix path and release coordination as soon as mitigation is verified

## Disclosure

Coordinated disclosure is required. Public disclosure should happen only after a fix is available or compensating controls are documented.
